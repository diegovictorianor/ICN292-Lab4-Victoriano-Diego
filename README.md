# ICN292-Lab4-Victoriano-Diego

Laboratorio 4 (SQL 1/2) del curso **ICN-292 Sistemas de Información para la Gestión**,

**Autor:** Diego Victoriano Rodríguez
**Profesores:** José Miguel González P. · José Luis Sáez T. · Patricio Cifuentes

## Descripción

Reconstrucción de la base `austral` de *Austral Editores* (autores y libros) en MySQL
con carga oficial de datos y diez consultas de gestión sobre el catálogo.
La base incluye las tablas `autores`, `libros`, `colecciones` y `pagos`, con claves
primarias, claves foráneas, `AUTO_INCREMENT`, `ENUM`, `DATE` y `DECIMAL(10,2)`.
